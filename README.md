## 🚀 Getting Started

Clone this repository:

```bash
git clone https://github.com/Kv23-corder/ReactBasics.git
````

Go to the project folder:

```bash
cd ReactBasics
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open the local development URL shown in the terminal.
